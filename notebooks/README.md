# Notebooks

Exploratory notebooks from the research phase. They mirror the legacy scripts and are kept for
provenance only; use the `lor2c` CLI for reproducible runs.

- `lor2c_prototype.ipynb` - LoR2C on TinyLlama (same content as `legacy/prototype.py`).
- `baseline_finetuning.ipynb` - full fine-tuning baseline used for the 7B vs 1B comparison.
